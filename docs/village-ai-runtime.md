# Optional village AI runtime

The village remains deterministic by default. Set `BOSON_VILLAGE_AI=1` to enable the server-side Jev and Vercel AI Gateway adapters. The adapters read `TYPESAFE_API_KEY` and `AI_GATEWAY_API_KEY` from `process.env`; to load a local ignored file explicitly, set `BOSON_AI_ENV_FILE` to its path before launching the village. Node 22+ provides `process.loadEnvFile()`. The viewer and browser never receive either key.

Jev selects only `walk_to`, `stop`, `look_at`, `turn_toward`, or `idle`; movement destinations are still selected from authored resident waypoints. Residents only look toward the configured explorer at 3–6 blocks and pause route movement inside 3 blocks. Exchanges move only the speaker and listener to the speaker's authored stop; other villagers keep their route loops. Jev is limited to 12 requests per process, one request per 10 seconds, a 1.5 second timeout, and the selected action is discarded if it is outside the allowlist. Vercel scene dialogue is requested in the background at most once per minute and three times per process, with an 8 second timeout, 80 output tokens, and a 2 KB response ceiling. It selects from authored same-speaker/same-listener line IDs; model text is never sent to the viewer. Provider errors and invalid output use authored behavior. There is no per-frame or per-resident model polling.

Usage logs are compact JSON on stderr and contain provider, returned model, per-call and cumulative request counts, input/output tokens, estimated per-call and cumulative cost, outcome, and dated rate source. A separate action event records the resident, selected bounded action, authored waypoint, and whether the choice came from Jev or local fallback. Logs exclude prompts, credentials, player identity, and runtime position. Cost is estimated only when token usage and the expected model are present; a missing rate or usage makes the cumulative estimate unknown. The rate snapshot was checked on 2026-10-24 UTC: Jev input US$42 per billion tokens with free output (TypeSafe blog); `openai/gpt-4.1-mini` US$0.0000004/input token and US$0.0000016/output token (AI Gateway model-list metadata). Actual billing may differ.

Implementation review drew two patterns from `rmalde/minecraft-agent`: keep action execution independent of planner latency, and treat model output as a selection among locally defined actions. It does not adopt open-ended tool execution, combat actions, plan authority over world truth, or automatic recovery loops. The Instagram production pipeline's cost ledger pattern records the model, rate basis, estimated amount, and a pre-set cap. This adapter applies those fields to local usage logs and hard request/output limits, without adding a paid media pipeline or persistent prompt archive.
