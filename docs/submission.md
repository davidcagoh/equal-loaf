# Submission

**Showcase:** Equal Loaf

**Track:** Conversation as the Interface

**One-liner:** Explore a local Minecraft village where conversation with a nearby resident is the interface to its story.

**Description (under 200 words):** Equal Loaf is a local Minecraft village demo about how conversation can reveal a shared story. Residents have different roles, motives, knowledge, and attributed memories; the player can speak naturally and follow conversational tangents. The native voice path selects one nearby resident, issues a short-lived Realtime credential from the local server, captures microphone input only during an explicit push-to-talk hold, and spatializes resident audio relative to movement. Native mode is opt-in and requires a Boson API key and microphone permission. The owner has accepted this one-to-one proximity behavior; dialogue timing around the dawn bell remains rough. Multi-party autonomous resident conversations and full physical hearing semantics are not implemented.
